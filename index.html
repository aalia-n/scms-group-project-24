Overview

Track B, manipulator: vision-guided pick. A UR3e in MuJoCo with a wrist-mounted RGB-D camera detects a target object on a tabletop, localises it from depth, plans an approach and executes a pick using PBVS. The object position is randomised between trials.

Generative AI Declaration

Our group used ChatGPT and Claude to initially break down the task and assign three unique parts to each group member, with subtasks aligned with the marking criteria. This helped ensure that all aspects of the task requirements were captured in the task delegation. We also independently used the chatbots to strengthen our understanding of key concepts (e.g. linearisation, Kalman filters, observers, LQR, PBVS and camera calibration) from the weekly lecture material and tutorial solutions, strategically targeting areas we were unsure or confused about.

Generating a GitHub Page and coding with HTML was completely new to our group, as this was not covered in any prerequisite subjects or within the scope of this subject. Hence, we used Claude to adapt the Nerfies index.html file, mentioned by Rafael in the video guide, to include the required components of our GitHub Page (e.g. an embedded YouTube video, AI declaration and team contributions).

When we experienced general errors involving GitHub branches, website deployment crashes, fatal merges, commit conflicts, missing Python modules and accidental virtual environment duplication, we used AI for troubleshooting. This saved considerable time by assisting with the interpretation of error messages. Our team utilised AI as a supplementary tool to address complications when team members were unable to collaboratively develop a solution first, rather than using it as a direct means of completing the required task. Before using AI, the team checked Canvas resources (e.g. using the Search function) for assistance.
